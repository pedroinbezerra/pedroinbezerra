## 🧭 Desenvolvimento orientado por Constituição

Uma das práticas mais importantes que adotei é definir uma **Constituição do Projeto** antes de permitir que agentes evoluam livremente uma base de código.

A Constituição funciona como a referência de mais alto nível para engenharia e produto.

Ela pode definir:

* Princípios arquiteturais
* Princípios de produto
* Invariantes de negócio
* Limites de segurança
* Padrões de engenharia
* Requisitos de evidência
* Critérios de decisão
* Responsabilidades que devem permanecer humanas
* Regras que agentes não podem sobrescrever

O objetivo é evitar que um agente resolva perfeitamente uma tarefa isolada enquanto prejudica o sistema como um todo.

```text
                    Constituição do Projeto
                              │
                              ▼
                 Arquitetura & Regras de Negócio
                              │
                              ▼
                      Contexto do Projeto
                              │
                              ▼
                    Skills Especializadas
                              │
                              ▼
                         Agentes de IA
                              │
                              ▼
         Investigar → Planejar → Implementar → Validar
                              │
                              ▼
                       Decisão Humana
```

## 🧠 Práticas de engenharia com IA

| Área                                   | Como aplico                                                                  |
| -------------------------------------- | ---------------------------------------------------------------------------- |
| **Constituições de Projeto**           | Princípios e restrições persistentes que orientam os agentes                 |
| **Skills customizadas**                | Conhecimento reutilizável ou específico para tarefas recorrentes             |
| **Context Engineering**                | Estruturação do contexto que precisa ser compreendido antes da execução      |
| **Agentes conscientes do repositório** | Trabalho direto sobre código, documentação e arquitetura reais               |
| **Workflows agentivos**                | Investigação → planejamento → implementação → testes → validação             |
| **Análise de Regras de Negócio**       | Uso de IA para compreender e confrontar comportamentos complexos do domínio  |
| **Análise Arquitetural**               | Avaliação de mudanças considerando o sistema como um todo                    |
| **Code Review**                        | Análise assistida de implementação, regressões e inconsistências             |
| **Documentação**                       | Manutenção do conhecimento técnico e de produto próximo da implementação     |
| **Avaliação de Modelos**               | Comparação de modelos para código, raciocínio, contexto e uso de ferramentas |
| **IA Local**                           | Execução e avaliação de modelos locais e configurações de inferência         |
| **Human-in-the-loop**                  | Decisões relevantes de produto e arquitetura continuam sob controle humano   |
