## 🧭 Engenharia orientada por Constituição

Uma das principais práticas que adotei foi a criação de uma **Constituição do Projeto**.

Ela funciona como a referência de mais alto nível para humanos e agentes de IA, definindo princípios e restrições que devem permanecer estáveis enquanto o produto evolui.

```text
                    Constituição do Projeto
                              │
                              ▼
                 Arquitetura & Regras de Negócio
                              │
                              ▼
                      Contexto do Projeto
                              │
                              ▼
                    Skills Especializadas
                              │
                              ▼
                         Agentes de IA
                              │
                              ▼
         Investigar → Planejar → Implementar → Validar
                              │
                              ▼
                       Decisão Humana
```

Uma Constituição pode definir:

`Princípios Arquiteturais` · `Princípios de Produto` · `Invariantes de Negócio` · `Limites de Segurança` · `Padrões de Engenharia` · `Critérios de Decisão` · `Requisitos de Evidência`

O objetivo é simples:

> Evitar que um agente resolva corretamente uma tarefa isolada enquanto piora o produto como um todo.
