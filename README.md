## 🧭 Constitution-first Engineering

One of the core practices I adopted is creating a **Project Constitution**.

It acts as the highest-level reference for both humans and AI agents, defining the principles and constraints that should remain stable while the product evolves.

```text
                    Project Constitution
                             │
                             ▼
                Architecture & Business Rules
                             │
                             ▼
                       Project Context
                             │
                             ▼
                    Specialized Skills
                             │
                             ▼
                        AI Agents
                             │
                             ▼
          Investigate → Plan → Implement → Validate
                             │
                             ▼
                      Human Decision
```

A Constitution can define:

`Architecture Principles` · `Product Principles` · `Business Invariants` · `Security Boundaries` · `Engineering Standards` · `Decision Criteria` · `Evidence Requirements`

The goal is simple:

> Prevent an agent from solving an isolated task correctly while making the overall product worse.
